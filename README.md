# calcraft-bot

Десктопная утилита для мониторинга аукциона StalCraft. Следит за списком предметов, сравнивает текущие цены выкупа со средними по рынку и сигналит, когда что-то продаётся заметно дешевле обычного. Плюс отслеживает выбросы.

## Что умеет

- Поиск по базе предметов игры (2000+ штук, с иконками и цветами редкости)
- Добавление предметов в список слежки с фильтром по уровню заточки (+0 до +15 или любой)
- Непрерывный опрос API аукциона — показывает самый дешёвый лот и медианную рыночную цену
- Пищит и выделяет красным, когда находит лот ниже вашего порога
- Отслеживает выбросы и оповещает при появлении нового

## Требования

- Python 3.11+
- PyQt6
- requests
- python-dotenv

Установка:
```
pip install PyQt6 requests python-dotenv
```

## Настройка

1. Получите API-ключи на портале разработчиков StalCraft
2. Запустите: `python main.py`
3. Введите Client ID и Client Secret во вкладке «Настройки»
4. Нажмите «Проверить API» — убедитесь, что ключи работают
5. Сохраните — настройки пишутся в `env.json` рядом со скриптом

## Использование

**Поиск предметов** — введите минимум 2 символа, фильтруйте по рангу и уровню заточки, жмите «Добавить в список слежки».

**Список слежки** — нажмите «Старт». Таблица обновляется каждый цикл: самый дешёвый лот и медиана из истории продаж. Лоты ниже порога выделяются красным.

**Выброс** — поставьте галочку, чтобы начать опрос. При новом выбросе приложение пищит и меняет заголовок вкладки.

## Настройки

| Параметр | По умолчанию | Описание |
|---|---|---|
| Интервал аукциона | 30 с | Как часто проверять каждый предмет |
| Интервал выброса | 60 с | Как часто проверять выброс |
| Порог оповещения | 0.70 | Алерт если цена < X × медиана (0.7 = скидка 30%) |

## Прочее

- Иконки скачиваются при первом поиске и кэшируются в папку `icons/`
- База предметов кэшируется в `items_cache.json`, обновить — кнопка «Обновить БД»
- Список слежки сохраняется в `watchlist.json` автоматически
- Рыночная цена считается как медиана последних 200 завершённых сделок, с учётом уровня заточки если он указан
