# Stalcraft Flea Seeker

Десктопная утилита для мониторинга аукциона StalCraft. Следит за нужными предметами, сравнивает текущую цену выкупа со средней по рынку и оповещает, когда что-то продаётся заметно дешевле обычного.

## Что умеет

- Поиск по базе предметов игры (2000+ штук, с иконками и цветами редкости)
- Список слежки с фильтром по уровню заточки (+0 до +15 или любая)
- Непрерывный опрос API аукциона — показывает самый дешёвый лот и медианную рыночную цену
- Пищит и выделяет строку, когда находит лот ниже заданного порога
- Тёмная и светлая тема
- Проверка обновлений при запуске — уведомление если вышла новая версия

## Готовый exe

Скачать последнюю версию можно на странице [Releases](https://github.com/bezdarnosti-yt/Stalcraft-Flea-Seeker/releases). Распаковывать ничего не нужно, просто запустите `calcraft-bot.exe`.

## Запуск из исходников

Требования: Python 3.11+

```
pip install PyQt6 requests
python main.py
```

## Настройка

1. Получите API-ключи на [портале разработчиков StalCraft](https://eapi.stalcraft.net)
2. Запустите приложение
3. Введите Client ID и Client Secret во вкладке «Настройки»
4. Нажмите «Проверить API» — убедитесь, что ключи работают
5. Сохраните — настройки пишутся в `env.json` рядом с программой

## Использование

**Поиск предметов** — введите минимум 2 символа, фильтруйте по рангу и уровню заточки, жмите «Добавить в список слежки».

**Список слежки** — нажмите «Старт». Таблица обновляется каждый цикл: самый дешёвый лот и медиана из истории продаж. Лоты ниже порога подсвечиваются.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| Интервал | 30 с | Как часто проверять каждый предмет |
| Порог | 0.70 | Алерт если цена < X × медиана (0.7 = скидка 30%) |

## Сборка exe (для разработки)

1. Скопируй `secrets.example.py` → `secrets.py`, впиши реальные ключи
2. Запусти `python build.py` из виртуального окружения с установленным PyInstaller
3. Готовый exe появится в `dist/calcraft-bot.exe`

`secrets.py` не коммитится в git.

## Прочее

- Иконки скачиваются при первом поиске и кэшируются в папку `icons/`
- База предметов кэшируется в `items_cache.json`, обновить — кнопка «Обновить БД»
- Список слежки сохраняется в `watchlist.json` автоматически
- Рыночная цена считается как медиана последних 200 завершённых сделок с учётом уровня заточки
- Логи каждого запуска пишутся в папку `logs/`
